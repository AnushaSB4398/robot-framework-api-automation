# Robot Framework API Automation

A reusable REST API automation framework built using **Robot Framework** and **RequestsLibrary**.

This project demonstrates automated testing of REST APIs, including CRUD operations, HTTP status-code checks, response-body validation, and negative test scenarios. It is designed as a portfolio project to showcase practical API test automation, reusable Robot Framework keywords, and maintainable test-suite structure.

## Key Features

- REST API testing using Robot Framework and RequestsLibrary
- Automated GET, POST, PUT/PATCH, and DELETE requests
- Validation of HTTP status codes and JSON response data
- Positive and negative API test scenarios
- Reusable keywords and variables
- Robot Framework HTML log and execution report generation
- Clean project structure suitable for regression testing
